2. Part, total and the rest

What you will be able to do

  • Pick out the part and the total in a sentence such as "Among 312 drivers, 289 wore seat belts."
  • Find how many in the group are not in the part.
  • Write the part out of the total as a decimal by dividing.
  • Compare two groups of different sizes by their decimals, not their counts.

Part divided by total

Many sentences name a whole group and then a smaller group inside it. The total is the whole group. It often follows words such as "among," "of the" or "out of." The part is the smaller group the sentence is about.

  • The part out of the total, as a decimal: divide the part by the total. The answer is between 0 and 1.
  • How many are not in the part: subtract the part from the total.
  • Two groups of different sizes: compare their decimals. The group with the bigger count does not always have the bigger decimal.

Three slips to watch for

  • Flipping the division. Total divided by part gives a number bigger than 1, which cannot be a part of the whole.
  • Writing a percent when a decimal is asked for. 0.360 point 3 6 and 36% are equal, but if the question says "as a decimal," type 0.360 point 3 6.
  • Answering for the wrong group. If the question asks about the ones who did not, use the leftover count.

Worked example: Food pantry bags

A food pantry served 80 families on Monday, and 52 of them brought their own bags. How many families did not bring bags, and what decimal describes the families who brought bags, out of all 80?

  1. Part: 52 brought bags. Total: 80 families.Label both numbers before doing anything.
  2. 80 − 52 = 2880 minus 52 equals 28The families who did not bring bags are the total minus the part.
  3. 52 ÷ 80 = 0.6552 divided by 80 equals 0 point 6 5Divide the part by the total. The result is less than 1, as it should be.

Answer: 28 families did not bring bags, and the decimal is 0.650 point 6 5.

3. Comparing decimals and reading symbols

What you will be able to do

  • Compare decimals that have different numbers of digits.
  • Read the symbols <, >, ≤, ≥ and ≠ in words.
  • Decide whether a statement such as 0.0076 ≤ 0.010 point 0 0 7 6 is less than or equal to 0 point 0 1 is true.
  • Find a value that fits a statement with two symbols, such as 2.5 < x < 4.12 point 5 is less than x is less than 4 point 1.

Line up the digits first

To compare two decimals, give them the same number of digits after the point by adding zeros at the end. Adding zeros at the end does not change a decimal. Then compare them as whole numbers.

For example, 0.40 point 4 becomes 0.4000 point 4 0 0 next to 0.3750 point 3 7 5. Since 400 is more than 375, 0.40 point 4 is larger.

Comparison symbols and how to read them

>is greater thanis greater than0.5 > 0.050 point 5 is greater than 0 point 0 5
≤is less than or equal tois less than or equal to0.05 ≤ 0.050 point 0 5 is less than or equal to 0 point 0 5

≠is not equal tois not equal to0.6 ≠ 0.060 point 6 is not equal to 0 point 0 6

The small, pointed end of < or > always faces the smaller number. A statement with two symbols, such as 2.5 < x < 4.12 point 5 is less than x is less than 4 point 1, says both things at once: x is greater than 2.52 point 5 and less than 4.14 point 1.

Three slips to watch for

  • Longer looks larger. 0.00890 point 0 0 8 9 has more digits than 0.010 point 0 1, but it is smaller: 0.00890 point 0 0 8 9 against 0.01000 point 0 1 0 0.
  • Shorter looks smaller. 0.10 point 1 has few digits, but it is 0.1000 point 1 0 0, larger than 0.0990 point 0 9 9.
  • Forgetting the "or equal to." 0.05 ≤ 0.050 point 0 5 is less than or equal to 0 point 0 5 is true, because ≤ allows the two numbers to be equal.

Worked example: Which is larger, 0.0004 or 0.03?

Which is larger, 0.00040 point 0 0 0 4 or 0.030 point 0 3?

  2. Compare 4 with 3000.00040 point 0 0 0 4 is 4 ten-thousandths and 0.03000 point 0 3 0 0 is 300 ten-thousandths.

Answer: 0.030 point 0 3 is larger, so 0.0004 < 0.030 point 0 0 0 4 is less than 0 point 0 3.

4. Subtracting to a negative number

What you will be able to do

  • Subtract a larger decimal from a smaller one and get a negative answer.
  • Keep the order of a subtraction as written.
  • Tell from the sign of a difference which number was larger.
  • Order negative decimals, positive decimals and 0.

Smaller minus larger is negative

When the number being subtracted is larger, the answer is negative. To find it, subtract the smaller number from the larger one, then put a minus sign in front.

  • Order matters: 0.62 − 0.48 = 0.140 point 6 2 minus 0 point 4 8 equals 0 point 1 4, but 0.48 − 0.62 = −0.140 point 4 8 minus 0 point 6 2 equals negative 0 point 1 4.
  • The sign of a difference tells you which number was larger. A negative result means the first number was the smaller one. A difference of 0 means the two numbers were equal.
  • On a number line, numbers get larger as you move right. A negative number closer to 0 is larger than one farther from 0, so −0.1 > −0.3negative 0 point 1 is greater than negative 0 point 3.

Three slips to watch for

  • Dropping the minus sign. Subtracting the smaller from the larger is a good way to find the size, but the answer still needs its sign.
  • Bigger digits, bigger number. For negatives this is backward: −0.142negative 0 point 1 4 2 is smaller than −0.058negative 0 point 0 5 8.
  • A negative difference does not mean negative numbers. Two positive numbers can have a negative difference.

Worked example: 0.48 − 0.62

Find 0.48 − 0.620 point 4 8 minus 0 point 6 2.

  1. 0.62 − 0.48 = 0.140 point 6 2 minus 0 point 4 8 equals 0 point 1 4The number being subtracted (0.62) is larger, so find the size by subtracting the other way.
  2. 0.48 − 0.62 = −0.140 point 4 8 minus 0 point 6 2 equals negative 0 point 1 4The first number was smaller, so the answer is negative.

Answer: −0.14negative 0 point 1 4

5. Rounding to two or three decimal places

What you will be able to do

  • Round to two decimal places and to three decimal places.
  • Round a negative number by rounding its digits and keeping the sign.
  • Carry correctly when a 9 rounds up.
  • Round a very small decimal to three decimal places.

How to round

  1. Find the last digit you will keep. For two decimal places it is the second digit after the point. For three decimal places it is the third.
  2. Look at the single digit right after it.
  3. If that digit is 5 or more, add 1 to the kept digit. If it is 4 or less, leave the kept digit alone.
  4. Drop every digit after the kept digit.

Negative numbers. Set the minus sign aside, round the digits the same way, then put the minus sign back.

Three slips to watch for

  • Rounding in steps from the right. Only the one digit right after the kept digit matters. 3.44493 point 4 4 4 9 to two decimal places is 3.443 point 4 4. Rounding to 3.4453 point 4 4 5 first and then to 3.453 point 4 5 is a slip.
  • Chopping instead of rounding. −1.8462negative 1 point 8 4 6 2 to two decimal places is −1.85negative 1 point 8 5, not −1.84negative 1 point 8 4.
  • A 9 that rounds up. It becomes 0 and adds 1 to the digit on its left. 0.049870 point 0 4 9 8 7 to three decimal places is 0.0500 point 0 5 0.

Worked example: Round −2.71649 to two decimal places

Round −2.71649negative 2 point 7 1 6 4 9 to two decimal places.

  1. Set the sign aside: 2.716492 point 7 1 6 4 9Round the digits first.
  2. Kept digit: the 1. Next digit: 6.The 6 is 5 or more, so the 1 becomes 2: 2.722 point 7 2.
  3. Put the sign back: −2.72negative 2 point 7 2The minus sign stays in front.

Answer: −2.72negative 2 point 7 2

Directions decide the answer. "Two decimal places" means exactly two digits after the point. "Three decimal places" means exactly three, even when they are zeros, as in 0.0500 point 0 5 0 or 0.0000 point 0 0 0.

6. Order of operations and percents

What you will be able to do

  • Multiply before subtracting in an expression such as 1 − 2 × 0.0251 minus 2 times 0 point 0 2 5.
  • Subtract a small decimal from 1 by lining up the decimal points.
  • Change a decimal such as 0.90 point 9 to a percent.
  • Do a two-step computation and give the result as a percent.

Multiplication comes before subtraction

  1. Parentheses first.
  2. Multiplication and division next, from left to right.
  3. Addition and subtraction last, from left to right.

So in 1 − 2 × 0.0251 minus 2 times 0 point 0 2 5, the multiplication happens first even though the subtraction is written first. Working left to right would give (1 − 2) × 0.025 = −0.025open parenthesis 1 minus 2 close parenthesis times 0 point 0 2 5 equals negative 0 point 0 2 5, a very different value.

Decimal to percent: multiply by 100, which moves the decimal point two places to the right, and add a percent sign. 0.950 point 9 5 is 95%, and 0.90 point 9 is 0.900 point 9 0, which is 90%.

Three slips to watch for

  • Working left to right past a multiplication. 1 − 2 × 0.041 minus 2 times 0 point 0 4 is not (1 − 2) × 0.04open parenthesis 1 minus 2 close parenthesis times 0 point 0 4.
  • Misplacing the decimal point when subtracting from 1. Write 1 as 1.0001 point 0 0 0 to match 0.0020 point 0 0 2: 1.000 − 0.002 = 0.9981 point 0 0 0 minus 0 point 0 0 2 equals 0 point 9 9 8.
  • Reading the digit as the percent. 0.90 point 9 is 90%, not 9%.

Worked example: 1 − 2 × 0.025 as a percent

Evaluate 1 − 2 × 0.0251 minus 2 times 0 point 0 2 5, then write the result as a percent.

  1. 2 × 0.025 = 0.052 times 0 point 0 2 5 equals 0 point 0 5Multiply first.
  2. 1 − 0.05 = 0.951 minus 0 point 0 5 equals 0 point 9 5Then subtract. Writing 1 as 1.001 point 0 0 lines up the points.
  3. 0.95 × 100 = 950 point 9 5 times 100 equals 95Multiply by 100 for the percent.

Answer: 0.950 point 9 5, which is 95%
