2. Comparing very small decimals

What you will be able to do

  • Compare two decimals by lining up the decimal points and filling in zeros.
  • Compare decimals that start with several zeros after the point.
  • Read the symbols <, >, ≤, ≥ and ≠ in words.
  • Read a value reported only as "less than" a small number.

Line up the places, then compare

A decimal with more digits is not always larger. To compare two decimals:

  1. Line up the decimal points.
  2. Fill in zeros at the end so both numbers have the same number of digits after the point. This does not change their values.
  3. Compare the digits from left to right. The first place where they differ decides which number is larger.

Every zero right after the decimal point makes a number ten times smaller. 0.050 point 0 5 is five hundredths, 0.0050 point 0 0 5 is five thousandths, and 0.00050 point 0 0 0 5 is five ten-thousandths.

Three slips to watch for

  • Longer is larger. 0.000830 point 0 0 0 8 3 has more digits than 0.0040 point 0 0 4, but it is smaller. Fill in zeros: 0.000830 point 0 0 0 8 3 against 0.004000 point 0 0 4 0 0.
  • Ignoring the zeros. Reading 0.00470 point 0 0 4 7 as "47" and 0.0350 point 0 3 5 as "35" makes the first look bigger. The zeros right after the point count.
  • Reading "or equal to" as strict. 0.03 ≤ 0.030 point 0 3 is less than or equal to 0 point 0 3 is true, because the two numbers are equal.

3. Subtracting in order and negative numbers

What you will be able to do

  • Subtract two decimals in the order they are given, first number minus second number.
  • Tell from the sign of a difference which number is larger.
  • Put negative and positive decimals in order from smallest to largest.
  • Read a statement such as −1.8 < x < −0.6negative 1 point 8 is less than x is less than negative 0 point 6 and tell whether 0 fits between the two ends.

Order matters in subtraction

8.3 − 5.1 = 3.28 point 3 minus 5 point 1 equals 3 point 2, but 5.1 − 8.3 = −3.25 point 1 minus 8 point 3 equals negative 3 point 2. Switching the order keeps the same digits and flips the sign. So the sign of a difference tells you which number was larger:

  • First minus second is positive: the first number is larger.
  • First minus second is negative: the first number is smaller.
  • First minus second is 0: the two numbers are equal.

To find a smaller number minus a larger one, subtract the smaller from the larger, then put a negative sign in front.

Negative numbers in order

On a number line, numbers get larger as you move to the right. Every negative number is less than 0, and every positive number is greater than 0. Among negative numbers, the one farther from 0 is the smaller one, so −4.2 < −1.7negative 4 point 2 is less than negative 1 point 7.

A statement such as −2.5 < x < 1.4negative 2 point 5 is less than x is less than 1 point 4 is read "x is between negative 2.5 and 1.4." Here 0 is between the two ends, because one end is negative and the other is positive. When both ends are positive, or both are negative, 0 is not between them.

Three slips to watch for

  • Always subtracting small from large. 12.4 − 15.112 point 4 minus 15 point 1 is negative 2.7, not 2.7.
  • Ordering negatives by their digits. 4.2 is more than 1.7, but −4.2negative 4 point 2 is less than −1.7negative 1 point 7.
  • Lining up the last digits instead of the decimal points. In 52.9 − 47.3552 point 9 minus 47 point 3 5, write 52.9 as 52.90 first.

Worked example: Tuesday minus Wednesday

The high temperature was 12.412 point 4 degrees Fahrenheit on Tuesday and 15.115 point 1 degrees Fahrenheit on Wednesday. Find Tuesday's high minus Wednesday's high, and say which day was warmer.

  2. 15.1 − 12.4 = 2.715 point 1 minus 12 point 4 equals 2 point 7The first number is smaller, so subtract the smaller from the larger.
  3. 12.4 − 15.1 = −2.712 point 4 minus 15 point 1 equals negative 2 point 7Put a negative sign in front. A negative difference means the first number, Tuesday, is smaller.

Answer: −2.7negative 2 point 7 degrees Fahrenheit, so Wednesday was warmer.

4. Rounding to two or three decimal places

What you will be able to do

  • Round a number to two decimal places or three decimal places.
  • Round a negative number: round the digits, then keep the negative sign.
  • Carry correctly when a 9 rounds up.
  • Write a result with the number of decimal places the directions ask for, including a zero at the end.

How to round

  1. Find the last digit you will keep. For two decimal places, that is the second digit after the point. For three decimal places, it is the third.
  2. Look at the single digit right after it.
  3. If that digit is 5 or more, add 1 to the kept digit. If it is 4 or less, leave the kept digit alone.
  4. Drop every digit after the kept digit.

Negative numbers. Round the digits exactly as you would for a positive number, then put the negative sign back in front. −1.0763negative 1 point 0 7 6 3 rounds the same way 1.07631 point 0 7 6 3 does.

A zero at the end. "Two decimal places" means exactly two digits after the point. If the rounded result is 2.72 point 7, write it as 2.702 point 7 0 to show both places. The value is the same, so this page accepts either one.

Three slips to watch for

  • Rounding in steps from the right. Only the one digit right after the kept digit matters. 2.714492 point 7 1 4 4 9 to two decimal places is 2.712 point 7 1. Rounding to 2.71452 point 7 1 4 5, then 2.7152 point 7 1 5, then 2.722 point 7 2 is a slip.
  • Chopping, especially with negatives. Dropping digits without looking at the next one is not rounding. −1.0763negative 1 point 0 7 6 3 to two decimal places is −1.08negative 1 point 0 8, not −1.07negative 1 point 0 7.
  • A 9 that rounds up. When a 9 goes up by 1, it becomes 0 and adds 1 to the digit on its left. −3.0961negative 3 point 0 9 6 1 to two decimal places is −3.10negative 3 point 1 0.

Worked example: Round −4.31762negative 4 point 3 1 7 6 2 two ways

Round −4.31762negative 4 point 3 1 7 6 2 to two decimal places, and then to three decimal places.

  1. Two decimal places: keep the 1, look at the 7The 7 is 5 or more, so the 1 becomes 2: 4.324 point 3 2. Put the sign back: −4.32negative 4 point 3 2.
  2. Three decimal places: keep the 7, look at the 6The 6 is 5 or more, so the 7 becomes 8: 4.3184 point 3 1 8. Put the sign back: −4.318negative 4 point 3 1 8.

Answer: −4.32negative 4 point 3 2 to two decimal places and −4.318negative 4 point 3 1 8 to three decimal places.

Directions decide the answer. "Round to two decimal places" means exactly two digits after the point. "Round to three decimal places" means exactly three. "Do not round" means type every digit the calculator shows.

5. One-line expressions with decimals

What you will be able to do

  • Multiply before subtracting in an expression such as 1 − 2 × 0.041 minus 2 times 0 point 0 4.
  • Subtract a decimal from 1 by writing 1 with the same number of decimal places.
  • Read an expression typed on one line, where * means multiply.
  • Give an answer as a decimal when the question asks for one.

Multiply first, then subtract

Multiplication comes before addition and subtraction, unless parentheses say otherwise. So 1 − 2 × 0.041 minus 2 times 0 point 0 4 means: first find 2 × 0.04 = 0.082 times 0 point 0 4 equals 0 point 0 8, then 1 − 0.08 = 0.921 minus 0 point 0 8 equals 0 point 9 2.

Typed on one line in a calculator or in StatCrunch, multiplication is written with a star: 1-2*0.041 minus 2 star 0 point 0 4. Parentheses around a single number, as in 1-2*(0.04)1 minus 2 star, open parenthesis 0 point 0 4 close parenthesis, do not change anything.

Subtracting from 1. Write 1 with as many decimal places as the other number: 1 − 0.08 = 1.00 − 0.08 = 0.921 minus 0 point 0 8 equals 1 point 0 0 minus 0 point 0 8 equals 0 point 9 2.

Three slips to watch for

  • Subtracting first. Working left to right as if subtraction came first gives (1 − 2) × 0.04 = −0.04open parenthesis 1 minus 2 close parenthesis, times 0 point 0 4, equals negative 0 point 0 4, a very different value.
  • Losing a place when subtracting from 1. 1 − 0.0021 minus 0 point 0 0 2 is 0.9980 point 9 9 8, not 0.980 point 9 8. Write 1 as 1.0001 point 0 0 0 first.
  • Adding a percent sign to a decimal. 0.950 point 9 5 and 95% are the same amount, but 0.95%0 point 9 5 percent is a much smaller number. When a question asks for a decimal, leave the percent sign off.

Worked example: 1 − 3 × 0.021 minus 3 times 0 point 0 2

6. Reading two-group tables and data lists

What you will be able to do

  • Read a value from a table that has one column for each group and a label on each row.
  • Match the groups named in a question to the right columns, even when the table lists them in a different order.
  • Count the values in two lists of different lengths.

Find the column, then the row

Many tables that compare two groups give each group its own column and label each row with what was measured. To read one value, find the column for the group, find the row for the measurement, and read the cell where they meet.

A question may name the groups in a different order than the table does. Before you compute anything, write down which group the question names first and which column holds it.

Three slips to watch for

  • Reading across the wrong row. Put a finger, or the cursor, on the row label and stay on that row.
  • Using the table's order instead of the question's. If the question says "second group minus first group," the table's left column is not automatically first.
  • Counting the longer list for both groups. Two lists side by side can have different lengths.
