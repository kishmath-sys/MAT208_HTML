2. Concepts

These checks cover items 1 and 2, the three scatterplot examples, and the REMINDER on pages 1 and 2 of the Section 2.4 notes.

Check 1 (Scatterplots). A coach records each player's height and vertical jump, both in inches. Which graph matches the description of a scatterplot in item 1?
Show answer

One point per player, at (height, jump), on a coordinate plane

Where this is: Item 1 (Scatterplots) on page 1 of the notes.

Check 2 (Ordered Pairs). A data set pairs x = hours of sleep with y = quiz score. One student slept 7 hours and scored 88. Which ordered pair is plotted for this student?
Show answer

(7, 88)

Where this is: Item 1 (Scatterplots) on page 1 of the notes.

Check 3 (Positive Linear Correlation). Look at the scatterplot below. Which description fits it?
Show answer

Positive linear correlation: the points slope upward from left to right

Where this is: Item 2 (Linear Correlation) and the positive linear correlation example on page 1 of the notes.

Check 4 (Negative Linear Correlation). Look at the scatterplot below. Every value on both axes is positive. Which description fits it?
Show answer

Negative linear correlation: the points slope downward from left to right

Where this is: Item 2 (Linear Correlation) on page 1 and the negative linear correlation example on page 2 of the notes.

Check 5 (No Linear Correlation). Look at the scatterplot below. Which description fits it?
Show answer

No linear correlation, because there is no clear line pattern

Where this is: Item 2 (Linear Correlation) on page 1 and the no linear correlation example on page 2 of the notes.

Check 6 (Correlation Is Not Causation). Over a year, months with more hot chocolate sales also tend to have more snow shovel sales, a positive correlation. Which statement matches the REMINDER on page 2?
Show answer

The two are related, but that does not mean one causes the other.

Where this is: The REMINDER (Correlation is NOT causation) on page 2 of the notes.
