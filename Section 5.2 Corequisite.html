2. Percents as decimals

What you will be able to do

  • Change a whole-number percent to a decimal, including one-digit percents such as 8%.
  • Change a percent with a decimal in it, such as 41.5%41 point 5 percent, to a decimal.
  • Change a percent less than 1%, such as 0.4%0 point 4 percent, to a decimal.
  • Compare numbers when some are percents and some are decimals.

Percent means "out of 100"

To change a percent to a decimal, drop the percent sign and divide by 100. Dividing by 100 moves the decimal point two places to the left. If the percent has no decimal point showing, it sits at the end: 64% is the same as 64.%64 point percent. Fill any empty places with zeros.

Percents and their decimals
PercentDivide by 100Decimal
52%52 ÷ 10052 divided by 1000.520 point 5 2
3%3 ÷ 1003 divided by 1000.030 point 0 3
12.5%12 point 5 percent12.5 ÷ 10012 point 5 divided by 1000.1250 point 1 2 5
0.2%0 point 2 percent0.2 ÷ 1000 point 2 divided by 1000.0020 point 0 0 2

Three slips to watch for

  • Moving only one place. 3% is 0.030 point 0 3, not 0.30 point 3. 0.30 point 3 is 30%.
  • Moving the point in the wrong direction. Going from a percent to a decimal always makes the number smaller. If your decimal is bigger than the percent number, you multiplied.
  • Dropping the percent sign and stopping. 0.2%0 point 2 percent is not 0.20 point 2. It is still a percent, so it needs to be divided by 100: 0.0020 point 0 0 2.

Worked example: Write 27.5% as a decimal

Write 27.5%27 point 5 percent as a decimal.

  1. 27.5 ÷ 10027 point 5 divided by 100Percent to decimal means divide by 100.
  2. 27.5 → 2.75 → 0.27527 point 5, then 2 point 7 5, then 0 point 2 7 5Move the decimal point one place left, then a second place left.
  3. Check: 0.2750 point 2 7 5 is a little more than 0.250 point 2 5, and 25% is a quarter27.5% is a little more than 25%, so the answer makes sense.

Answer: 0.2750 point 2 7 5 (not 2.752 point 7 5, which would be 275%)

3. Subtracting from 1 and multiplying decimals

What you will be able to do

  • Subtract a decimal from 1 by writing 1 with enough zeros.
  • Check a subtraction by adding back.
  • Multiply a whole number by a decimal and place the decimal point correctly.
  • Multiply three numbers in a row and check the size of the answer.

Subtracting a decimal from 1

Write 1 with a decimal point and as many zeros as the other number has decimal places. Then line up the points and subtract, borrowing as usual.

  • 1 − 0.41 minus 0 point 4 becomes 1.0 − 0.4 = 0.61 point 0 minus 0 point 4 equals 0 point 6
  • 1 − 0.061 minus 0 point 0 6 becomes 1.00 − 0.06 = 0.941 point 0 0 minus 0 point 0 6 equals 0 point 9 4

Check by adding back. Your answer plus the number you subtracted must equal exactly 1.

Multiplying by a decimal

Multiply as if there were no decimal points, then count the digits after the point in the decimal and put that many in the answer. A quick estimate catches a point in the wrong place: multiplying by a decimal between 0 and 1 always gives an answer smaller than the number you started with.

Three slips to watch for

  • Subtracting each digit from 10. For 1.00 − 0.831 point 0 0 minus 0 point 8 3, borrowing leaves 9 tenths and 10 hundredths, not 10 and 10. The answer is 0.170 point 1 7, not 0.270 point 2 7.
  • Bringing the decimal part down. 1 − 0.831 minus 0 point 8 3 is not 1.831 point 8 3. Subtracting must give something smaller than 1.
  • Losing the decimal point. 45 × 0.645 times 0 point 6 is 27, not 270 and not 2.72 point 7. Six tenths of 45 is a bit more than half of 45.

Worked example: 1 − 0.245 and 250 × 0.32

Find 1 − 0.2451 minus 0 point 2 4 5, then find 250 × 0.32250 times 0 point 3 2.

  1. 1.000 − 0.245 = 0.7551 point 0 0 0 minus 0 point 2 4 5 equals 0 point 7 5 5Write 1 as 1.0001 point 0 0 0 so both numbers have three decimal places, then subtract.
  2. 0.755 + 0.245 = 1.0000 point 7 5 5 plus 0 point 2 4 5 equals 1 point 0 0 0Check by adding back. It comes out to exactly 1.
  3. 250 × 32 = 8,000250 times 32 equals 8,000For the multiplication, first multiply without the decimal point.
  4. 250 × 0.32 = 80.00 = 80250 times 0 point 3 2 equals 80 point 0 0 equals 800.320 point 3 2 has two digits after the point, so the answer gets two: 80.0080 point 0 0. Estimate: 0.320 point 3 2 is about a third, and a third of 250 is about 83. The answer 80 fits.

Answer: 0.7550 point 7 5 5 and 80

4. Square roots and order of operations

What you will be able to do

  • Use a calculator to find a square root and round it.
  • Multiply everything under a square root sign before taking the root.
  • Do the multiplication first in expressions such as 36 − 2(4.5)36 minus 2 times 4 point 5.
  • Keep every digit until the last step, then round once.

What a square root sign covers

The square root of a number is the value that, multiplied by itself, gives the number. For example, √49 = 7the square root of 49 equals 7 because 7 × 7 = 497 times 7 equals 49. Most square roots are not whole numbers, so a calculator gives a long decimal that you round.

The bar on top of a square root sign works like parentheses. In √(120 × 0.4 × 0.6)the square root of, open parenthesis 120 times 0 point 4 times 0 point 6 close parenthesis, multiply everything under the bar first, then take the square root of the product. Typed on one line, many calculators write this as sqrt(120*0.4*0.6)s q r t, open parenthesis 120 star 0 point 4 star 0 point 6 close parenthesis, where * means multiply. The parentheses must hold the whole product.

Multiplication before addition and subtraction

A number written right next to parentheses means multiply: 2(4.5)2 times 4 point 5 is 2 × 4.52 times 4 point 5. In 36 − 2(4.5)36 minus 2 times 4 point 5, the multiplication happens first: 2 × 4.5 = 92 times 4 point 5 equals 9, then 36 − 9 = 2736 minus 9 equals 27.

Three slips to watch for

  • Taking the root of only the first number. √120 × 0.4 × 0.6the square root of 120, times 0 point 4 times 0 point 6 is about 2.62 point 6, but √(120 × 0.4 × 0.6)the square root of the product 120 times 0 point 4 times 0 point 6 is about 5.45 point 4.
  • Subtracting first. 36 − 2(4.5)36 minus 2 times 4 point 5 is not 34 × 4.534 times 4 point 5. Multiply first.
  • Rounding in the middle. Rounding a square root before you use it in the next step can change the final answer. Keep every digit until the end.

Worked example: √(120 × 0.4 × 0.6) and 50 − 2(3.5)

Find √(120 × 0.4 × 0.6)the square root of, open parenthesis 120 times 0 point 4 times 0 point 6 close parenthesis rounded to one decimal place. Then find 50 − 2(3.5)50 minus 2 times 3 point 5.

  1. 120 × 0.4 × 0.6 = 28.8120 times 0 point 4 times 0 point 6 equals 28 point 8Multiply everything under the square root sign first.
  2. √28.8 = 5.36656…the square root of 28 point 8 equals 5 point 3 6 6 5 6 and so onThen take the square root.
  3. 5.36656… → 5.45 point 3 6 6 5 6 rounds to 5 point 4One decimal place: keep the 3, look at the 6, round up.
  4. 50 − 2(3.5) = 50 − 7 = 4350 minus 2 times 3 point 5 equals 50 minus 7 equals 43Multiply first, then subtract.

Answer: 5.45 point 4 and 43

5. Rounding to three or four decimal places

What you will be able to do

  • Find the third and fourth decimal places, even when the number starts with zeros after the point.
  • Round to three or four decimal places.
  • Carry correctly when a 9 rounds up.
  • Keep a final zero when the directions ask for a set number of decimal places.

How to round to three or four decimal places

  1. Count places to the right of the decimal point. Every digit counts, including zeros right after the point. In 0.04728160 point 0 4 7 2 8 1 6, the first place is 0, the second is 4, the third is 7 and the fourth is 2.
  2. Find the last place you will keep: the third place for three decimal places, the fourth for four.
  3. Look at the single digit right after it. If it is 5 or more, add 1 to the kept digit. If it is 4 or less, leave the kept digit alone.
  4. Drop every digit after the kept digit. Keep any zeros up to the kept place, even at the end.

Four slips to watch for

  • Skipping the zeros after the point. Three decimal places of 0.059170 point 0 5 9 1 7 is 0.0590 point 0 5 9. Writing 0.05920 point 0 5 9 2 counts three digits starting at the 5, which is four decimal places.
  • Chopping instead of rounding. 0.083670 point 0 8 3 6 7 to three decimal places is 0.0840 point 0 8 4, not 0.0830 point 0 8 3.
  • A 9 that rounds up. When a 9 goes up by 1, it becomes 0 and adds 1 to the digit on its left. 0.38960 point 3 8 9 6 to three decimal places is 0.3900 point 3 9 0.
  • Rounding in steps from the right. Only the one digit right after the kept digit matters. 0.213480 point 2 1 3 4 8 to three decimal places is 0.2130 point 2 1 3. Rounding to 0.21350 point 2 1 3 5 first and then to 0.2140 point 2 1 4 is a slip.

Worked example: Round 0.0472816 two ways

Round 0.04728160 point 0 4 7 2 8 1 6 to four decimal places, and then to three decimal places.

  1. Four decimal places: keep the 2, look at the 8The places are 0, 4, 7, 2. The 8 is 5 or more, so the 2 becomes 3: 0.04730 point 0 4 7 3.
  2. Three decimal places: keep the 7, look at the 2The 2 is 4 or less, so the 7 stays: 0.0470 point 0 4 7.

Answer: 0.04730 point 0 4 7 3 to four decimal places and 0.0470 point 0 4 7 to three decimal places.

Directions decide the answer. "Round to four decimal places" means exactly four digits after the point, so a final zero stays: 0.27500 point 2 7 5 0, not 0.2750 point 2 7 5. "Do not round" means type every digit the calculator shows.

6. Inequality symbols and comparing decimals

What you will be able to do

  • Read each of the symbols ≤less than or equal to, ≥greater than or equal to, <less than, >greater than and = in words.
  • Tell whether the number next to the symbol is included.
  • List or count the whole numbers that make a statement true.
  • Compare decimals that have different numbers of digits.

Reading the symbols

The table reads each symbol and shows which whole numbers from 0 to 6 make the statement true when the number on the right is 3.

A memory aid: the extra line under ≤less than or equal to and ≥greater than or equal to is part of an equals sign, so the number itself is included.

Comparing decimals

To compare decimals, line up the points and give both numbers the same number of places by adding zeros at the end. Then compare them as you would whole numbers. A decimal with more digits is not automatically bigger: 0.04120 point 0 4 1 2 has more digits than 0.050 point 0 5, but 0.0412 < 0.05000 point 0 4 1 2 is less than 0 point 0 5 0 0.

Three slips to watch for

  • Including the number when it is not included. x < 3x less than 3 does not include 3.
  • Forgetting 0. When the whole numbers start at 0, 0 counts too.
  • Thinking longer is larger. 0.09950 point 0 9 9 5 is less than 0.10 point 1, even though it has more digits.

Worked example: Count and compare

Using whole numbers from 0 to 8, how many make x ≤ 2x less than or equal to 2 true? Then decide which is smaller, 0.03890 point 0 3 8 9 or 0.050 point 0 5.

  1. 0, 1, 2Less than or equal to includes 2 itself, and the list starts at 0. That is 3 whole numbers.
  2. 0.03890 point 0 3 8 9 and 0.05000 point 0 5 0 0Give both numbers four decimal places. Now compare 389 ten-thousandths with 500 ten-thousandths.
  3. 0.0389 < 0.050 point 0 3 8 9 is less than 0 point 0 5389 is less than 500.

Answer: 3 whole numbers, and 0.03890 point 0 3 8 9 is smaller.
