2. Inequality symbols and comparison words

What you will be able to do

  • Read each inequality symbol out loud correctly.
  • Turn phrases such as "more than," "at least" and "no more than" into symbols.
  • Tell whether a phrase includes the amount itself or leaves it out.
  • Find the statement that covers exactly the numbers another one leaves out.

Six symbols and their words

An inequality symbol compares two amounts. The open side of <the less than sign and >the greater than sign always faces the larger amount, and the point faces the smaller one. So 3 < 83 is less than 8 reads "3 is less than 8," and 8 > 38 is greater than 3 reads "8 is greater than 3."

Inequality symbols and the words that go with them

≥the greater than or equal to signis greater than or equal toat least, no less than

The symbols with a bar underneath, ≥the greater than or equal to sign and ≤the less than or equal to sign, include the amount itself. The others leave it out.

Three slips to watch for

  • Reading the symbol backwards. y > 12y is greater than 12 says y is greater than 12. Read from left to right, and check that the open side faces the larger amount.
  • Dropping the "or equal to" part. "At least 5" means 5 or more, so 5 itself counts. It is x ≥ 5x is greater than or equal to 5, not x > 5x is greater than 5.
  • Counting the amount itself in "larger than." 30 is not larger than 30. "Larger than 30" starts just above 30.

Worked example: No more than 50 pounds

A suitcase can weigh no more than 50 pounds. Write this with a symbol, using b for the weight.

  1. "No more than 50" means 50 or lessThe weight can be 50 exactly, or anything under 50.
  2. 50 is allowed, so use a symbol with a barThe weight is the smaller side or equal, so the point of the symbol faces b.

Answer: b ≤ 50b is less than or equal to 50

3. Comparing decimals

What you will be able to do

  • Compare two decimals by giving them the same number of decimal places.
  • Know that a decimal with more digits is not automatically larger.
  • Know which zeros change a value and which do not.
  • Decide whether a number is between two other numbers.

Same number of places, then compare

  1. Line up the decimal points.
  2. Write zeros at the end of the shorter decimal until both have the same number of digits after the point. Zeros at the end do not change the value, so 0.050 point 0 5, 0.0500 point 0 5 0 and 0.05000 point 0 5 0 0 are all the same number.
  3. Compare the digits after the point as if they were whole numbers.

Money can help: 0.050 point 0 5 dollars is 5 cents, and 0.0430 point 0 4 3 dollars is 4.3 cents.

Place values of 0.0430 point 0 4 3 and 0.0500 point 0 5 0
NumberOnesTenthsHundredthsThousandths
0.0430 point 0 4 30043
0.0500 point 0 5 00050

A number is between two others when it is larger than the smaller one and smaller than the larger one. Check it against both ends.

Three slips to watch for

  • Longer is not larger. 0.0430 point 0 4 3 looks bigger than 0.050 point 0 5 because 43 is more than 5, but as thousandths it is 43 against 50.
  • A zero right after the point matters. 0.60 point 6 is 6 tenths, but 0.060 point 0 6 is only 6 hundredths.
  • Checking only one end. To be between two numbers, a number has to pass both checks, not just one.

Worked example: Which is smaller, 0.043 or 0.05?

Which is smaller, 0.0430 point 0 4 3 or 0.050 point 0 5?

  1. 0.0430 point 0 4 3 and 0.0500 point 0 5 0Give both numbers three decimal places by adding a zero to the end of 0.05.
  2. 43 thousandths and 50 thousandths43 is less than 50, so 0.043 is the smaller number.

Answer: 0.043 < 0.050 point 0 4 3 is less than 0 point 0 5

4. Percents and decimals

What you will be able to do

  • Change a percent to a decimal, including single-digit percents such as 6%.
  • Change a decimal to a percent, including small decimals that give a percent under 1%.
  • Compare numbers written in different forms.

Two places, in the right direction

  • Percent to decimal: divide by 100. The decimal point moves two places to the left. Fill any empty places with zeros, so 6% is 0.060 point 0 6.
  • Decimal to percent: multiply by 100. The decimal point moves two places to the right, then add the percent sign.

A percent can be less than 1%. For example, 0.0050 point 0 0 5 is 0.5%0 point 5 percent.

Three slips to watch for

  • Moving only one place. 6% is 0.060 point 0 6, not 0.60 point 6, which is 60%.
  • Adding a percent sign without converting. 0.0150 point 0 1 5 is 1.5%, not 0.015%0 point 0 1 5 percent.
  • Typing a percent sign on a decimal answer. When a question asks for a decimal, 0.060 point 0 6 and 0.06%0 point 0 6 percent are different amounts.

Worked example: Write 4% as a decimal and 0.0185 as a percent

Write 4% as a decimal, and write 0.01850 point 0 1 8 5 as a percent.

  1. 4 ÷ 100 = 0.044 divided by 100 equals 0 point 0 4Percent to decimal: move the point two places left, with a zero in front of the 4.
  2. 0.0185 × 100 = 1.850 point 0 1 8 5 times 100 equals 1 point 8 5Decimal to percent: move the point two places right, then add the percent sign.

Answer: 0.040 point 0 4 and 1.85%1 point 8 5 percent

5. Expressions that start with 1 minus

What you will be able to do

  • Subtract a small decimal from 1 by lining up the decimal points.
  • Read 2x2 x as "2 times x."
  • Multiply before subtracting in an expression such as 1 − 2x1 minus 2 x.
  • Write the result as a percent.

Line up, multiply first, then subtract

  • Write 1 with as many decimal places as the number you subtract: 1 = 1.001 point 0 0 = 1.0001 point 0 0 0.
  • A number written right next to a letter means multiply, so 2x2 x means 2 times x.
  • Multiplication comes before subtraction, so in 1 − 2x1 minus 2 x, find 2x first and subtract it from 1 last.

Three slips to watch for

  • Subtracting first. (1 − 2) × 0.04 = −0.04open parenthesis 1 minus 2 close parenthesis, times 0 point 0 4 equals negative 0 point 0 4, which is not the same as 1 − 2 × 0.041 minus 2 times 0 point 0 4.
  • Lining up the wrong places. 1 − 0.041 minus 0 point 0 4 is 0.960 point 9 6, not 0.60 point 6.
  • Skipping the 2. In 1 − 2x1 minus 2 x, the 2 doubles x before anything is subtracted.

Worked example: 1 minus 2x when x = 0.04

Evaluate 1 − 2x1 minus 2 x when x = 0.04x equals 0 point 0 4, and write the result as a percent.

  3. 0.92 × 100 = 920 point 9 2 times 100 equals 92Multiply by 100 to write the result as a percent.

Answer: 0.920 point 9 2, which is 92%
