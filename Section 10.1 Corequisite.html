2. Negative numbers on the number line

What you will be able to do

  • Tell which of two negative numbers is smaller.
  • Put positive and negative decimals in order from least to greatest.
  • Find the distance between two numbers, and tell which number is closer to a target such as −1negative 1.
  • Read a statement such as −1 ≤ x ≤ 1negative 1 is less than or equal to x, which is less than or equal to 1.

Left is less

On a number line, numbers get larger as you move right and smaller as you move left. Every negative number is to the left of 0, so every negative number is less than 0 and less than every positive number.

  • Two negatives: the one farther from 0 is farther left, so it is the smaller number. −38negative 38 is less than −26negative 26.
  • Distance between two numbers: count from the smaller number up to the larger one. Distance is never negative. From −1negative 1 up to −0.86negative 0 point 8 6 is 0.140 point 1 4.
  • Closer to a target: find each distance to the target. The smaller distance wins.
  • A range with ≤ on both sides: −1 ≤ x ≤ 1negative 1 is less than or equal to x, which is less than or equal to 1 means x is at least −1negative 1 and at most 1. Both −1negative 1 and 1 themselves are included.

Three slips to watch for

  • Ordering by the digits. −0.75negative 0 point 7 5 is less than −0.4negative 0 point 4, even though 75 is bigger than 4. With negatives, bigger digits mean farther left.
  • Dropping the minus sign. 0.970 point 9 7 and −0.97negative 0 point 9 7 are almost 2 apart. The sign is part of the number.
  • Treating distance as negative. The distance from −0.93negative 0 point 9 3 to −1negative 1 is 0.070 point 0 7, not −0.07negative 0 point 0 7.

3. Comparing decimals and inequality symbols

What you will be able to do

  • Compare two decimals that have different numbers of digits.
  • Read the symbols <, ≤, >, ≥ and ≠, and tell whether a statement that uses them is true.
  • Read a value written as < 0.0001less than 0 point 0 0 0 1.
  • Count how many values meet a rule such as "at most."

Line up the decimal points

To compare decimals, write them with the same number of digits after the point by adding zeros at the end. Adding zeros at the end does not change the value. Then compare them like whole numbers.

0.047 → 0.04700 point 0 4 7 becomes 0 point 0 4 7 0 and 0.03850 point 0 3 8 5: since 470 is more than 385, 0.047 > 0.03850 point 0 4 7 is greater than 0 point 0 3 8 5.

Inequality symbols and how to read them
SymbolRead it asExample that is true
<is less than0.02 < 0.20 point 0 2 is less than 0 point 2
≤is less than or equal to0.3 ≤ 0.300 point 3 is less than or equal to 0 point 3 0
>is greater than0.6 > 0.590 point 6 is greater than 0 point 5 9

The small end of < and > always points at the smaller number. A display that shows < 0.0001less than 0 point 0 0 0 1 means the value is some number smaller than 0.00010 point 0 0 0 1, too small to show with four decimal places.

Three slips to watch for

  • Longer looks larger. 0.03120 point 0 3 1 2 has more digits than 0.050 point 0 5, but 0.0312 < 0.05000 point 0 3 1 2 is less than 0 point 0 5 0 0.
  • Forgetting that ≤ includes equal. 0.25 ≤ 0.250 point 2 5 is less than or equal to 0 point 2 5 is true. 0.25 < 0.250 point 2 5 is less than 0 point 2 5 is false.
  • Miscounting zeros. 0.00010 point 0 0 0 1 is one ten-thousandth. 0.0010 point 0 0 1 is ten times bigger.

Worked example: Compare 0.047 and 0.0385

Which is larger, 0.0470 point 0 4 7 or 0.03850 point 0 3 8 5? Is 0.0385 ≤ 0.0470 point 0 3 8 5 is less than or equal to 0 point 0 4 7 true?

  1. 0.0470 and 0.03850 point 0 4 7 0 and 0 point 0 3 8 5Add a zero so both have four digits after the point.
  2. 470 is more than 385So 0.0470 point 0 4 7 is the larger number.
  3. 0.0385 ≤ 0.0470 point 0 3 8 5 is less than or equal to 0 point 0 4 7The smaller number is on the left of ≤, so the statement is true.

Answer: 0.0470 point 0 4 7 is larger, and the statement is true.

4. Rounding to two or three decimal places

What you will be able to do

  • Round to two or three decimal places.
  • Round a negative number and keep its minus sign.
  • Carry correctly when a 9 rounds up.
  • Round a very small number to three decimal places.

How to round

  1. Find the last digit you will keep. For two decimal places, it is the second digit after the point. For three decimal places, it is the third.
  2. Look at the single digit right after it.
  3. If that digit is 5 or more, add 1 to the kept digit. If it is 4 or less, leave the kept digit alone.
  4. Drop every digit after the kept digit.

Negative numbers. Round the digits exactly as you would for the positive number, then put the minus sign back. −4.58362negative 4 point 5 8 3 6 2 to three decimal places is −4.584negative 4 point 5 8 4, because 4.583624 point 5 8 3 6 2 rounds to 4.5844 point 5 8 4.

Three slips to watch for

  • Rounding in steps from the right. Only the one digit right after the kept digit matters. 0.314490 point 3 1 4 4 9 to three decimal places is 0.3140 point 3 1 4. Rounding to 0.31450 point 3 1 4 5 first and then to 0.3150 point 3 1 5 is a slip.
  • Chopping instead of rounding. Dropping digits without looking at the next one is not rounding. −0.68352negative 0 point 6 8 3 5 2 to three decimal places is −0.684negative 0 point 6 8 4, not −0.683negative 0 point 6 8 3.
  • A 9 that rounds up. When a 9 goes up by 1, it becomes 0 and adds 1 to the digit on its left. 2.999622 point 9 9 9 6 2 to three decimal places is 3.0003 point 0 0 0.

Worked example: Round −4.58362 two ways

Round −4.58362negative 4 point 5 8 3 6 2 to three decimal places, and then to two decimal places.

  1. Three decimal places: keep the 3, look at the 6The 6 is 5 or more, so the 3 becomes 4: −4.584negative 4 point 5 8 4. The minus sign stays.
  2. Two decimal places: keep the 8, look at the 3The 3 is 4 or less, so the 8 stays: −4.58negative 4 point 5 8.

Answer: −4.584negative 4 point 5 8 4 to three decimal places and −4.58negative 4 point 5 8 to two decimal places.

Very small numbers. A number such as 0.000040 point 0 0 0 0 4 rounded to three decimal places is 0.0000 point 0 0 0, because the digit after the third place is 0. Typing 0 for an answer like this is accepted on this page.

5. Reading paired data and plotting points

What you will be able to do

  • Read a value from a table where each column is one pair of values.
  • Write a pair as an ordered pair (x, y) with the values in the right order.
  • Plot a point that has a negative coordinate.
  • Read units such as "in thousands" in a row label.

Tables of paired values

Some tables list two or more values for each person, ride or day. Each column belongs to one case, and each row is one variable. To find a value, find the right column first, then go to the row you need.

When a pair is written as an ordered pair (x, y), the first number is x and tells you how far to move left or right from (0, 0). The second number is y and tells you how far to move up or down. Positive x moves right and negative x moves left. Positive y moves up and negative y moves down.

Units in the label. A label such as "Population (thousands)" means each number counts thousands. A value of 4.75 means 4.75 × 1,000 = 4,7504 point 7 5 times 1,000 equals 4,750.

Three slips to watch for

  • Swapping the order. (3, 5) and (5, 3) are different points. The x value always comes first.
  • Losing the minus sign when plotting. (3, −3negative 3) is below the horizontal axis, not above it.
  • Reading the wrong row. In a table with several rows, check the row label before you copy a number.
